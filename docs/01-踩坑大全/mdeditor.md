# Markdown 编辑器推荐

为需要编辑 Markdown 的文案人员写的推荐指南

## VS Code (首推)

VS Code 是一款轻量级的，跨平台的代码编辑器，配合合适的插件，可以非常方便地编辑 Markdown 文件。

::: info 1. 下载并安装

导航至 [VS Code 下载页面](https://code.visualstudio.com/Download)

对于不了解的， Win10/Win11 桌面电脑/标准笔记本电脑用户：选择 [Windows](https://code.visualstudio.com/sha/download?build=stable&os=win32-x64-user)

对于高级用户/非 Windows 系统用户：按照对应系统名称和架构下载安装

:::

::: info 2.安装插件
为你的 VS Code 安装下列插件：

- [中文拓展包](https://marketplace.visualstudio.com/items?itemName=MS-CEINTL.vscode-language-pack-zh-hans)
- [约定式提交](https://marketplace.visualstudio.com/items?itemName=vivaxy.vscode-conventional-commits)
- [Github 风格 Markdown 渲染套件](https://marketplace.visualstudio.com/items?itemName=bierner.github-markdown-preview)
- [Prettier 格式工具](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)
- [[可选]更好的浅色 VS Code 主题：Atom One Light](https://marketplace.visualstudio.com/items?itemName=akamud.vscode-theme-onelight)
- [[可选]更好的深色 VS Code 主题：Atom One Dark](https://marketplace.visualstudio.com/items?itemName=akamud.vscode-theme-onedark)

然后重启你的 VS Code

:::

## Obsidian

Obsidian 是一款所见即所得的 Markdown 笔记软件

:::warning

如要使用 Obsidian 与 Github 项目协作，请注意写作风格, 尤其注意 `Callout/Github Alert` 相关章节

- [Obsidian 写作风格](https://publish.obsidian.md/help-zh/编辑与格式化/基本格式语法)
- [Github 写作风格](https://docs.github.com/zh/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)

:::

::: info 下载并安装

导航至 [Obsidian 下载页面](https://obsidian.md/download)

对于不了解的， Win10/Win11 桌面电脑/标准笔记本电脑用户：选择 Windows 直接下载

对于高级用户/非 Windows 系统用户：按照对应系统名称和架构下载安装
:::

> [!IMPORTANT]
> 下载速度慢，有两个办法：
>
> 1.  科学上网
> 2.  前往[Obsidian 各版本安装包 - 通知发布 - Obsidian 中文论坛](https://forum-zh.obsidian.md/t/topic/13718/2)
